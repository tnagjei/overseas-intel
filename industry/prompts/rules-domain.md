# 行业术语

术语帮助准确表达，不用于虚构事实或推断商业效果。
保留 WordPress、WooCommerce、Gutenberg、Cloudflare、Vercel、Ghost、Stripe、n8n 以及插件、产品专名。
SEO、API、MCP、Core Web Vitals 保留英文；Newsletter 可译“邮件通讯”；membership 译“会员”；subscription 译“订阅”；churn 译“流失”；retention 译“留存”。
index/indexing 按上下文译“索引/收录”；crawling 译“抓取”；ranking 译“排名”，三者不可混用。
theme 译“主题”，plugin 译“插件”；breaking change 译“破坏兼容性的变更”；deprecated 译“已弃用”，不是已经移除。
漏洞保留 CVE、影响范围、受影响版本、修复版本与已确认状态；严重度不等于读者已受影响。
支付、价格、税务与订阅保留币种、周期、地区、资格条件和费用构成。未交代基数的百分比不能改为绝对收益。
产品机会保留需求证据与适用条件。流量、收入、转化、成本与因果只按原文支持的主张表述。
保留代码、命令、版本、URL 与必要参数，不补写性能和盈利承诺。AI、Agent、模型与提示词按实际工作流解释；Token、模型专名与版本保留英文。
