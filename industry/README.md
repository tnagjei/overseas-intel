# 海外情报行业包

五个栏目围绕个人出海业务，配置 18 个公开信源与 24 个主题。评分类型、五轴权重与双次评分不变。

- site.ts：站名、说明、MCP 与采集身份。
- reading.ts：个人首页、导航文案与业务关注标签。
- taxonomy.ts、topics.json：栏目、标签、实体与主题。
- sources.json：RSS/Atom 信源，默认摘要与原文链接。
- prompts/：相关性、评分、内容理解和报告规则。
- selection.ts、features.ts：待校准门槛与已关闭的 AI 专属模块。
- brand/、pages/、changelog.json：私人站点品牌与说明。

来源和实际验收结果见 ../docs/personal-v1.md。
