## 改动

- 五个栏目、18 个公开信源、24 个主题；初次回填每源最多 8 条。
- 接收非 AI 的建站、SEO、工具和订阅资料，按业务影响、证据与可复用性筛选。
- 保留七种内容类型、五轴权重、双次评分；阈值仍为 T1=60、T1_5=65、T2=76，待真实样本校准。
- 不虚构收入、需求量、插件安装情况或因果。
- 关闭模型榜、Codex 重置监控，以及默认采集和模型调用。
- 默认本机监听；Caddy 对页面、RSS、API、MCP 统一认证，空密码哈希不能启动入口。
- 独立雷达图标与海外报告刊头；个人版隐私与使用说明。
- 测试中的示例类别迁移到新行业，不改原被验证的规则。
- 增加配置检查、免费试抓与就绪检查，Docker 构建生成图标。

## 启用真实情报

1. 按根 README 初始化本地 .env 和管理员密码。
2. 填写模型地址、Key 与模型名，开启采集和模型调用后重启。
3. 在后台先确认信源、预算与模型配置，再试跑少量资料。
4. 自己标注 100–200 条相关性与精选样本后再考虑调整门槛。

目前交付的是可运行程序和验证过的个人行业配置，没有填写真实凭据，没有长期托管的阅读地址。
