# 个人业务阅读入口

本轮在海外情报独立仓库修改首页、导航与资讯卡片，代码提交：`771d06bfe764cc5239687fcd34e5fae40b853ec2`。

## 行为

- 首页提供六个关注入口：站点安全、搜索收录、产品机会、工具定价、订阅收款与流程自动化。
- 关注项沿用已有标签筛选，跨栏目查找精选；可继续叠加栏目筛选。筛选状态体现在 URL 中，支持返回与直接分享到自己的设备。
- 首页展示当前筛选标题与「清除筛选」。有筛选时聚焦相关精选，完整首页显示原热点模块。
- 精选卡片在电脑和手机上展示业务分类、标签与「为什么值得看」；点击标签可继续查找。
- 精选为空时，保留类别、标签和来源渠道，进入对应范围的全部动态。
- 首页和导航文字、关注项集中在 `industry/reading.ts`；现有行业包通配导出可直接加载。
